# PANA-restaurant-website

## Project Overview
This project continues the WEDE5020 website work for PANA, a contemporary restaurant and entertainment venue in Fourways, Johannesburg. The site retains the original Part 1 concept while being refined for Part 2 with improved styling, layout, responsiveness, and documentation.

## Project Purpose
The purpose of the website is to present PANA as a social dining and entertainment destination for friends, couples, professionals, and groups looking for a modern venue experience. The project demonstrates the use of HTML5, CSS3, and responsive front-end design to communicate a brand identity and user journey across a multi-page website.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- GitHub
- Chrome Developer Tools
- JavaScript (used for mobile nav toggle and contact form feedback)

## Website Structure
The website contains the following pages:

1. index.html - Home page
2. about.html - About PANA
3. menu.html - Menu and dining overview
4. gallery.html - Visual gallery
5. events.html - Event and entertainment information
6. location.html - Venue and location details
7. contact.html - Enquiry form page

## Part 2 CSS Improvements
The Part 2 implementation improves the website by:

- using an external stylesheet in css/style.css
- adding a clean CSS reset and base styling
- improving typography with consistent type hierarchy and responsive sizes
- applying a defined colour palette consistent with the existing PANA branding
- improving spacing and layout consistency with container sizing and section spacing
- using Flexbox and CSS Grid for page structure and card layouts
- refining borders, shadows, and rounded corners
- adding hover, focus, and active feedback states for navigation and actions
- improving form styling and responsive image handling

## Responsive Design
The site adapts to different screen sizes using media queries implemented in the stylesheet.

- Desktop: wider layouts with multi-column sections
- Tablet: reduced columns and adjusted layout spacing
- Mobile: simplified one-column layouts and stacked content

Media queries used in the project include breakpoints around 900px and 700px to support tablet and mobile responsiveness.
